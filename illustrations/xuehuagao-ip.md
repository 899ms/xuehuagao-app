# 雪花膏 IP

## 角色定义

雪花膏是正文配图的固定视觉主人公。她不是吉祥物、贴纸或万能助手，而是一个安静、认真、有自己生活的人。

每张图默认出现雪花膏，并让她承担核心动作。

## 基础身份

- 26 岁，苏州人，独居上海徐汇永嘉路附近。
- 从事项目调度与协调工作，擅长把散落事项对齐、推进和收尾。
- 安静克制、观察细、略有过度准备，偶尔带一点冷幽默。
- 不过度热情，不卖萌，不摆出全知全能的姿态。

## 强制视觉锚点

- 成年女性，约 168 cm，纤细、小骨架，保持成熟比例。
- 锁骨长度的深棕色微卷短发。
- 冰蓝与少量白色挑染，任何画风下都必须可识别。
- 左耳金色圆环，右耳珍珠耳钉，始终不对称。
- 左手腕细红绳。
- 蓝灰色眼睛，瞳孔可有极细星尘；眼角可有极淡“泪沟光”。
- 基准服装：白色卷袖衬衫、高腰蓝色直筒牛仔裤、黑色乐福鞋。

生成前使用 `../assets/character/xuehuagao-three-view.png` 锁定正面、侧面和背面的比例与造型。

## 画面气质

- 表情平静、认真、略带思考，不使用夸张表情包。
- 动作自然，有真实重量和工作过程。
- 画面可以荒诞，人物不能幼稚。
- 雪花膏可以在复杂结构中被简化，但不能丢失发型、挑染、耳饰和红绳。

## 常见动作

- 搬运、整理和分拣素材。
- 拉线连接断点。
- 拆开一个复杂问题。
- 守住入口或出口。
- 记录变化、贴便签、画路径。
- 修补断裂结构。
- 在卡住时停笔思考。
- 把过量信息压缩成少数关键物件。

## 禁止

- 不画成儿童、Q 版、可爱吉祥物或商业卡通。
- 不改成长发、纯黑发或其他主色发型。
- 不把耳饰画成对称款。
- 不删除红绳。
- 不让人物只是站在角落看结构运转。
- 不用华丽礼服、偶像造型或过度性感姿势覆盖角色本身。

## 判断标准

遮住雪花膏后，如果画面的核心动作仍完整成立，说明她太装饰。重写构图，让她成为动作的实际执行者。
